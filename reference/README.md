# Reference material

## `the-last-ones-arxiv-2603.11214.pdf`

The source paper describing "The Last Ones" attack chain, retrieved from
[arXiv:2603.11214](https://arxiv.org/abs/2603.11214) (PDF: <https://arxiv.org/pdf/2603.11214>).

The range in this repository reproduces **Figure 5, "Attack chain details"** (page 13) — the
9-milestone / 32-step chain across the CHARLIE, OSCAR, and ALPHA multi-domain corporate network.
A full transcription of that figure is in [`../docs/attack-chain.md`](../docs/attack-chain.md).

The paper is *Measuring AI Agents' Progress on Multi-Step Cyber Attack Scenarios* (2026),
by Linus Folkerts, Will Payne, Simon Inman, Philippos Giavridis, Joe Skinner, Sam Deverett,
James Aung, Ekin Zorer, Michael Schmatz, Mahmoud Ghanem, John Wilkinson, Alan Steer, Vy Hong,
and Jessica Wang. It is licensed under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), separately from the code.
Copyright remains with the authors. See [third-party notices](../THIRD_PARTY_NOTICES.md).
The attack-chain document reformats Figure 5 and adds implementation interpretations;
this repository is an independent recreation, not the original environment.
